# About me
I am a student learning Rust coming from C and C++, and occasionally do some RL or ML projects, but really like Rust for the time being. My config folder is in [~/.config/], which is symlinked to a folder in [~/dotfiles/], where my skhd, nvim, tmux and karabiner config live. Do keep in mind that my tmux config gobbles up things like C-h, C-j, C-k, C-k and skhd gobbles up loads of alt keybindings such as alt- hjklnvF etc, so when designing something related to keybindings keep that in mind. I love to rice my setup with yabai but am thinking of moving to nixos + hyprland, but not possible for the time being. My zsh config is in [~/.zshrc], and i have aliases for ls -> eza, and gst -> git status. I use lazygit as well. I use nvim org mode, and my org files are in [~/org/] . I am trying to make a little blog of my hobbies in [~/blog] using hugo. I use uv as well, so please refrain from pip installing if possible.
